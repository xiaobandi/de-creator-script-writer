## 30 秒上手

```bash
git clone <本仓库地址> && cd de-creator-script-writer
pip install pyyaml
python3 tests/run.py            # 先跑一遍自检，确认环境与契约都对得上
```

试用（把 `<输入>` 换成本人真实材料）：

```text
请以「短视频脚本创作师」的身份，帮我跑「选题转脚本」。
材料如下：<输入>
要求：只使用材料里出现过的数字，缺的写 <待填>；对外文案停在待确认状态。
```
