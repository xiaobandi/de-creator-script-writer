## 目录约定

```text
kb/
├── schema.yaml          # 切分 / 检索 / 引用参数（可版本化）
├── corpus/              # 真实语料（.gitignore，仅保留 .gitkeep 与 samples/）
│   └── samples/         # 可公开的少量样例，供测试用
└── README.md
```

## 三条硬规则

1. **无匹配不许编**：检索不到就明确说「知识库无匹配」，宁可空手而归。
2. **必须带出处**：任何引用知识库的产出都要附 `来源: <文件>#<片段>`。
3. **报时效**：语料的最后更新日期要随引用一起给出；超过 `schema.yaml`
   里 `stale_after_days` 的语料要在产出里标黄。
