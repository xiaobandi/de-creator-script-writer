## 示例一 · 标准用法（真实运行）

```bash
python3 ../../tools/compliance_scan.py --file examples/input/copy.txt
python3 ../../tools/compliance_scan.py --file examples/input/post.txt --platform 小红书
```

**真实输出**：

```console
目标平台：通用　词表版本：2026.09-baseline
结论：警告
  - AI 味评分 100，建议改写
AI 味评分：100/100
命中总数：0
目标平台：小红书　词表版本：2026.09-baseline
结论：阻断
  - 平台引流 命中 1 处
  - AI 味评分 100，建议改写
AI 味评分：100/100
命中总数：1
  [平台引流] 加我微信
→ 命中高危，不得直接对外发布；逐条替换后重扫。
```

> AI 味评分直接给出「套话密度」量化结果，把主观感受变成可对比的数字

> **注意**：AI 味是**风格问题不是合规问题**，不要与违禁词混在一张清单里。

## 示例二 · 用你自己的材料

```bash
python3 ../../tools/compliance_scan.py --file /path/to/your-data/copy.txt
```

把 `examples/input/` 下的文件换成你的真实材料即可；**输入结构不要改**，改了字段名脚本会读不到。

---

## 示例三 · 嵌进自动化链路

```bash
set -e
python3 ../../tools/compliance_scan.py --file examples/input/copy.txt || exit 2   # 非零即阻断
```

脚本是纯函数：文件/stdin 进、stdout 出、退出码表达判定，因此可以被 CI、定时任务或上层工作流直接编排。
