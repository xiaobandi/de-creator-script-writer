# 使用示例

技能：**口语化改写**（`wf-creator-script-colloquial`）

> ⚠️ **本技能的真实效果示例尚未补齐**：以下仅为输入 / 输出契约（**不构成效果证据**）与平台兼容性验证结果。发布前须补至少 3 组「真实输入 → 实际产出」。

---

## 示例一 · 标准用法（真实运行）

```bash
python3 ../../tools/compliance_scan.py --file examples/input/formal.txt --platform 抖音
```

**真实输出**：

```console
目标平台：抖音　词表版本：2026.09-baseline
结论：放行
AI 味评分：20/100
命中总数：0
```

> 先扫风险再改口播——改写前必须知道哪些词动不得

> **注意**：口语化**不等于**可以带风险词；改写后必须重扫一遍。

---

## 示例二 · 用你自己的材料

```bash
python3 ../../tools/compliance_scan.py --file /path/to/your-data/formal.txt --platform 抖音
```

把 `examples/input/` 下的文件换成你的真实材料即可；**输入结构不要改**，改了字段名脚本会读不到。

---

## 示例三 · 嵌进自动化链路

```bash
set -e
python3 ../../tools/compliance_scan.py --file examples/input/formal.txt --platform 抖音 || exit 2   # 非零即阻断
```

脚本是纯函数：文件/stdin 进、stdout 出、退出码表达判定，因此可以被 CI、定时任务或上层工作流直接编排。
