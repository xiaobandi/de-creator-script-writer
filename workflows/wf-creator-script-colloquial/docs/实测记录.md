### 步骤 2：人设口语

**做**：依 `persona-tone-lib` 固化人设语气画像，再用 `colloquial-rewrite` 把书面初稿改为人设口语，并以脚本复检 AI 味是否下降。

#### 2.1 `persona-tone-lib`：人设语气画像卡

**输入来源**：`07` 一、主理人人设 + 语气样本。

```
## 身份
手作香氛主理人「林晓」，29 岁，前广告公司文案，一个人做香薰。

## 语气（5 个形容词）
温和、理性、具体、克制、慢

## 用词偏好
- 口头禅：「说实话」「这么说吧」
- 多讲场景与细节，少用形容词
- 用第一人称讲自己的选择，不讲大道理

## 禁用表达
- 「家人们」「绝绝子」「闭眼入」「冲鸭」
- 装可怜卖惨、贬低同行

## 示例句（正 / 反）
正：「说实话，这支蜡烛的成本我算过，大头在香精。」
反：「家人们冲鸭！！这款神仙蜡烛绝绝子，闭眼入！！！」
```

（依据：字段全部取自 `07` 一；「5 个形容词」为 SKILL 输出契约要求数量。）

#### 2.2 `colloquial-rewrite`：改写为林晓口语

**改写对照表（关键改写）**

| 书面原句 | 人设口语改写 | 改写理由（`colloquial-rewrite` 执行步骤） |
|---|---|---|
| 随着养宠家庭数量持续增长，如何…成为许多消费者关注的问题 | 说实话，养猫之后，我把家里的蜡烛都收起来了。 | 拆长句、去书面连接词「随着」、加口头禅「说实话」、换第一人称叙事 |
| 传统明火蜡烛存在一定的安全隐患 | 不是蜡烛不好。是猫会跳上桌，明火总归不放心。 | 换主动、把抽象「安全隐患」落到具体场景（猫跳上桌） |
| 无火藤条香氛采用植物精油基底与无酒精配方，无需点燃即可持续散发香气 | 后来就换了无火的——藤条香氛，没有酒精，150 毫升，8 根藤条，能撑 60 天。 | 去「采用…配方」书面腔，数字前置到口播节奏位 |
| 香调为青苔、湿土与白松香 | 味道是青苔、湿土。怎么说呢，像下过雨的院子。 | 换自然口语、加停顿「怎么说呢」、用具象比喻替代香调名词堆砌 |
| 无火方案是一个值得考虑的选择 | 猫在不在家，我都能安心摆着。 | 删结论式表达，换成个人使用感受 |

**产出：人设口语稿（改写后，实测 AI 味 0/100）**

### 步骤 3：断句 / 语气词适配

**做**：把口语稿按**呼吸长度**切句，补自然语气词，适配口播。

**产出：口播终稿（断句 / 语气词版）**

```text
说实话，养猫之后，我把家里的蜡烛都收起来了。
不是蜡烛不好。
是猫会跳上桌，明火总归不放心。
后来就换了无火的——
藤条香氛，150 毫升，8 根藤条，能撑 60 天。
没有酒精，味道是青苔、湿土。
怎么说呢，像下过雨的院子。
猫在不在家，我都能安心摆着。

（待人工确认）
```

**断句 / 语气词改动说明**

| 改动 | 从 → 到 | 理由 |
|---|---|---|
| 长句切分 | 「不是蜡烛不好，是猫会跳上桌…」→ 拆成两句 | 口播按换气切句，书面逗号不足以支撑停顿（SKILL 已知陷阱「口播稿要换气」） |
| 破折号停顿 | 「后来就换了无火的——」 | 制造停顿，为下一个数字信息点（150 毫升）留呼吸位 |
| 语气词 | 「怎么说呢」 | 取自人设口头禅库（`07`：口头禅「说实话」「这么说吧」，「怎么说呢」为同族自然停顿词） |
| 短句收尾 | 「不是蜡烛不好。」独立成句 | 一镜一信息，便于镜头切换 |

**依据与结论**
- 切句依据 `colloquial-rewrite` 已知陷阱「口播稿要换气：句子要按呼吸长度切」。
- 未使用「家人们/绝绝子/闭眼入」，符合 `07` 一 忌讳行。

**未决 · 待填**
- 抖音口播 60–90 秒对应的实际时长：终稿正文 **121 字（含标点，不含换行）**，秒数因无折算口径 → `<待填>`。
- 镜头 / 分镜：本工作流只做口播稿，不含分镜（分镜属 `wf-creator-script-storyboard`）→ 本稿不输出分镜。
